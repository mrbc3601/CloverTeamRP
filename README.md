# CloverTeam — макет сайта

В архиве:
- `index.html` — главная страница и разделы;
- `style.css` — оформление и адаптивная версия;
- `script.js` — переключение разделов и формы входа/регистрации.

## Важно
Это пока фронтенд-макет. Формы входа и регистрации отображаются, но ещё не подключены к серверу и `admins.json`. Не размещайте `admins.json` внутри `/var/www/cloverteam` — файл должен храниться вне публичной директории сайта.

## Установка на VPS
Сначала сделайте резервную копию текущего сайта, затем загрузите файлы в `/var/www/cloverteam/`.
После копирования проверьте конфигурацию командой `sudo nginx -t`.
